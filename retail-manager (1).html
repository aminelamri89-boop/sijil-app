🔌 خطوة أخيرة — وصّل قاعدة البيانات

باش البيانات تتشارك بين أكثر من جهاز (أنت والموظف)، لازم تنشئ قاعدة بيانات مجانية على Supabase وتربطها بالتطبيق. تاخذ 3 دقائق ومرة وحدة فقط:

  1. روح لـ supabase.com واعمل حساب مجاني، ثم أنشئ مشروع جديد (New Project)
  2. من القائمة الجانبية افتح SQL Editor والصق هذا الكود ثم اضغط Run: 
    create table sijil_store (
  id text primary key,
  data jsonb,
  updated_at timestamptz default now()
);
alter table sijil_store enable row level security;
create policy "allow all" on sijil_store
  for all using (true) with check (true);
  3. روح لـ Project Settings → API وانسخ Project URL و anon public key
  4. الصقهم تحت وسجّل، وسيتم حفظهم داخل هذا الملف نفسه:

⚠️ ملاحظة أمان: هذا الإعداد يجعل قاعدة البيانات مفتوحة لأي شخص يملك الرابط والمفاتيح (بدون تسجيل دخول) — مناسب للاستخدام الداخلي بينك وبين موظف موثوق، وليس لبيانات حساسة جدًا.
